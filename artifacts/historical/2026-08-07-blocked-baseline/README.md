# Historical: blocked-baseline acceptance report (2026-08-07, commit `bdb3f95`)

**This is not current demo evidence. Do not cite it as demo readiness.**

These files record an earlier state of this branch, when a real LIVE `demo:run` was blocked in the
development environment (insufficient free disk for the validator image set, and no GitHub
credentials reachable from the worktree). At that point the pipeline had been verified only through
its typed ports, and `examples/canonical-run/manifest.json` still held `PLACEHOLDER_AFTER_LIVE_RUN`
values.

They are kept because the reasoning is part of the branch's history, and because the report was
honest about what it could not prove. They are moved out of `artifacts/demo-readiness/` so that the
current evidence directory contains only mutually consistent current evidence:
`run-summary.json` here says `liveDataHubContext: null` and `completedStatus: null`, which directly
contradicts the live golden run that directory now describes.

Current evidence lives in:

- `artifacts/demo-readiness/` — regenerated by `pnpm export-evidence <run-id>` from the live run;
- `artifacts/demo-runs/<run-id>/golden-run.json` — the golden run snapshot;
- `artifacts/demo-runs/FINAL_EXECUTION_REPORT.md` — the current execution report.
